# RemoteLink 简短演示文档

## 1. 演示目标

本演示展示 RemoteLink 的基本使用流程：

1. 启动 server。
2. 启动 client 并搜索 server。
3. 建立远程连接。
4. 查看远程画面并进行鼠标键盘控制。
5. 从 client 向 server 发送文件。
6. 断开连接并停止服务。

## 2. 演示环境

建议环境：

- 两台位于同一局域网的 Windows 设备，或同一台设备上同时运行 client 和 server。
- 防火墙允许 RemoteLink 使用 TCP 端口 `45454` 和 UDP 端口 `45455`。
- server 端桌面处于可采集状态。

默认端口：

| 用途 | 端口 |
| --- | ---: |
| TCP 远程连接 | 45454 |
| UDP 设备发现 | 45455 |

## 3. 启动 server

1. 运行 server 程序。
2. 查看界面上的本机名称和本机 IP。
3. 如果需要自定义 TCP 端口，在“监听端口”输入框中输入端口号。
4. 点击“启动服务”。
5. server 开始监听 TCP 连接，并同时开启 UDP 发现响应。

启动成功后，系统日志区域会显示服务启动信息。

## 4. 启动 client 并搜索设备

1. 运行 client 程序。
2. client 启动后会自动进行一次局域网搜索。
3. 如果没有看到设备，可以点击“刷新”重新搜索。
4. 在设备下拉框中选择目标 server。

如果搜索不到设备，优先检查：

- client 和 server 是否在同一局域网。
- server 是否已经点击“启动服务”。
- 防火墙是否放行 UDP `45455`。
- 虚拟机网络是否使用桥接或可互通模式。

## 5. 建立远程连接

1. 在 client 选择目标设备。
2. 点击“连接”。
3. 连接成功后，client 会发送心跳。
4. server 收到心跳后启动屏幕采集。
5. client 开始显示 server 的远程画面。

连接成功后：

- client 状态栏显示已连接。
- server 状态区域显示 client 地址和连接时长。
- client FPS 标签显示画面显示帧率。

## 6. 远程控制

连接成功后，在 client 的远程画面区域中操作：

- 移动鼠标：server 鼠标跟随移动。
- 左键、右键、中键：server 执行对应鼠标按键。
- 滚轮：server 执行滚轮事件。
- 键盘输入：server 执行键盘按下和释放。

鼠标坐标按远程画面比例发送。server 根据自己的屏幕尺寸换算为真实屏幕坐标。

## 7. 文件发送

1. client 点击“发送文件”。
2. 选择本地文件。
3. client 开始读取文件并通过 TCP 发送。
4. server 显示文件接收状态和进度。
5. 文件接收完成后，server 日志显示保存路径。

server 默认保存目录：

```text
server 程序目录/downloads
```

当前文件发送使用写缓冲水位控制，网络较慢时会自动暂停读取新文件块，等 socket 缓冲下降后继续发送。

## 8. 断开连接

可以从 client 或 server 任一侧断开：

- client 点击“断开连接”。
- server 点击“断开连接”。
- server 点击“停止服务”。

断开后：

- server 停止截图。
- server 释放鼠标按键状态。
- client 停止接收画面。
- 如果正在发送文件，client 会请求取消文件发送。

## 9. 常见问题

### 9.1 client 搜不到 server

检查 server 是否启动服务，确认防火墙允许 UDP `45455`，并确认两端网络互通。

### 9.2 连接成功但画面很卡

可能原因：

- 网络带宽不足。
- Wi-Fi 或虚拟机网络抖动。
- JPEG 帧较大。
- server socket 写缓冲出现积压。

可以观察 client 的 received fps、decoded fps、display fps，以及 server 的发送日志。

### 9.3 鼠标键盘没有响应

检查 client 是否已经连接成功，并确认远程画面控件获得焦点。键盘事件需要远程画面区域具有键盘焦点。

### 9.4 文件接收位置在哪里

文件保存在 server 程序目录下的 `downloads` 文件夹中。

## 10. 演示结束

演示结束时建议：

1. client 点击断开连接。
2. server 点击停止服务。
3. 检查 server 日志确认连接已断开、服务已停止。
